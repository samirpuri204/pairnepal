PairNepal FAQ — the things people ask first

PairNepal is also written as Pair Nepal, pair nepal or pairnepal — it is the same tool. Below are the answers people look for before their first transfer: what the size limit really is, whether both devices need the same Wi-Fi, where your files actually go, and what to do when a device will not show up.

Basics

What is PairNepal?

A free browser tool that sends files directly from one device to another — phone to laptop, Mac to Windows, Android to iPhone. Both devices open the same web page, they find each other, and the file moves between them. No account, no app to install, no cable.

Do I need to install anything or create an account?

No. PairNepal runs entirely in the browser. You can optionally add it to your home screen so it opens like an app, but nothing has to be installed and there is no signup.

Which devices and browsers does it work on?

Any device with a modern browser: Android and iPhone, Windows, macOS and Linux, in Chrome, Safari, Firefox and Edge. If it can open a web page, it can send and receive. That includes the awkward direction — Android to iPhone, or Windows to Mac — that normally needs a cable or a cloud drive.

Is PairNepal free?

Yes. Free to use, with no account, no subscription and no per-transfer charge.

How is this different from a cloud drive or a messaging app?

Messaging apps recompress photos and cap video length. Cloud drives need an account and push your file through someone else's disk before the other person can download it. PairNepal copies the bytes straight across, so a 48 MP photo arrives as the 48 MP photo, and a 4 GB video is not a problem.

Sending & receiving

Is there a file size limit?

No upload cap. Because the file travels directly between the two devices instead of being uploaded to a server, the only limits are your browser and your free disk space. A 4 GB video transfers fine on a local network.

Do both devices need to be on the same Wi-Fi?

No. The same network is the fastest and simplest path, and devices on it appear automatically. If the two devices are on different networks, pair them once with a six-digit code, or join a temporary five-letter public room, and the transfer still works.

How do I pair two devices on different networks?

Open the pair-device option on one device to get a six-digit code, then enter that code on the other. The two devices are linked, so from then on they see each other whenever both are online — useful for a phone on mobile data and a laptop at home. You can unpair from the same panel at any time.

What is a public room?

A temporary five-letter room that several devices can join at once, so you do not have to pair them one by one. Anyone with the room link or code can join while it is open, so treat it like a shared folder: use it for a quick hand-off, not for anything private. Leaving the room removes you from it.

How do I receive multiple files?

Send as many as you like at once. Multiple files arrive as a single zip so they land together, and progress is shown per file. Images and videos keep their original quality — bytes are copied, never re-encoded.

Can I send text instead of a file?

Yes. There is a built-in text message option, which is convenient for a link, a password or an address that is painful to retype on a phone.

Privacy & security

Where do my files actually go?

Straight to the other device. PairNepal's server only introduces the two devices to each other and then steps out of the way — the file data never passes through it and is never stored on it.

Is the transfer encrypted?

The connection is a direct peer-to-peer WebRTC data channel, which is encrypted in transit, and only the receiving device gets the file. PairNepal cannot read your files, because they do not travel through PairNepal's servers.

Do you keep my files or my device name?

No files are stored. The display name you see is generated on your device so you can recognise it; you can edit or replace it, and it is only used so the other side knows who is sending. Nothing about a transfer is kept after the session ends.

Who can see that my device is online?

Only devices on the same local network, or devices that joined the same room or were paired with you. PairNepal does not publish a directory of users, and a device is discoverable only while the page is open.

Troubleshooting

Why can I not see the other device?

Check that both devices are on the same Wi-Fi network and that neither is on a VPN. Some routers, and most public and guest networks, isolate clients from each other so they cannot talk directly. If that is the case, or the devices are simply in different places, use a pair code or join the same public room instead — both work across networks.

Why is the transfer slow?

Speed follows the weakest link: an older phone, the 2.4 GHz Wi-Fi band, or a congested network. On a good local network transfers typically run at tens of megabytes per second. Moving both devices closer to the router, or off a guest network, is usually the fastest fix.

The transfer stopped halfway. What now?

Keep both tabs open until the transfer finishes — a sleeping phone or a backgrounded browser tab can pause the connection. Reopen the receiving tab and send again; nothing is left half-written on the other side, and the file is not corrupted if the transfer is restarted.

Why does PairNepal make sounds?

A transfer has no visible feedback until it finishes, so sound reports what is happening — a device appearing, a file sent, a transfer complete. Sound is off by default and you turn it on when you want it; the choice is remembered on your device.

Can I use it offline?

Opening the page needs an internet connection once. After that a transfer between two devices on the same local network works because the data goes directly between them — but both devices still need the page loaded, and the first visit has to reach the site.
