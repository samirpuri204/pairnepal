How it works

Three steps, no account

PairNepal is a web page, not an installation. Both devices open it, they see each other, and the transfer runs directly between them.

Open it on both devices

Same Wi-Fi and they appear automatically. On different networks, pair once with a six-digit code or join a shared room.

Pick who receives

Tap the device name, or drag files anywhere on the page first and choose a recipient after.

They accept, it moves

Files transfer directly. Multiple files arrive as a single zip, and progress is shown per file.

Why it's different

Built for the file that is too big to send

Messaging apps recompress photos and cap video. Cloud drives need an account and a round trip through someone else's disk. PairNepal does neither.

Original quality, always

Bytes are copied, not re-encoded. A 48 MP photo arrives as the 48 MP photo, not a 2 MB preview.

It stays between you

The transfer is peer to peer. PairNepal's server introduces the two devices and then steps out of the way.

Every platform, including that one

Android to iPhone, Windows to Mac, Linux to anything. If it has a modern browser, it works.

Rooms for different cities

Not on the same network? Join a five-letter room code and devices connect across the internet instead.

Installable, and it keeps working offline as an app shell

Add PairNepal to your home screen and it behaves like a native app: it opens instantly, remembers your device name, and keeps paired devices between sessions.

Sound design

Seven cues, made from scratch

The interface has a voice. Every cue below is synthesised in the browser with the Web Audio API — no audio files, nothing to download, and nothing that plays until you ask for it.

Sound is off until you turn it on — tap any cue above, or the speaker icon in the header of the app. Your choice is remembered. Every cue is one-shot and stops by itself; nothing loops.

Questions

The things people ask first

The short answers are below. For the full set — size limits, pair codes, how rooms work across networks, privacy, and what to do when a device will not appear — read the PairNepal FAQ.

Is there a file size limit?

Your browser and your disk are the limits. Because files never pass through our server, there is no upload cap — a 4 GB video is fine on a local network.

Do both devices need the same Wi-Fi?

No. Same network is the fastest and simplest path, but you can pair devices once with a six-digit code, or join a temporary five-letter room, and transfer across different networks.

Where do my files go?

Straight to the other device. The server only helps the two devices find each other; the file data travels directly between them.

Do I need to install anything?

No. PairNepal runs in the browser. You can optionally add it to your home screen so it opens like an app.

Why does it make sounds?

Because a transfer has no visible feedback until it finishes. Sound is off by default and you turn it on when you want it.
